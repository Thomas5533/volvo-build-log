# Volvo Project build log

Build log for a 1989 Volvo 240 DL: installed parts, races, maintenance, future mods, photos and contributors.

**Live site:** https://thomas5533.github.io/volvo-build-log/

## Updating the site

1. Edit `Volvo Site.html` on your computer and click **Save file**.
2. On this repository's page, click **Add file → Upload files**, drag in `Volvo Site.html`, and click **Commit changes**.
3. The live site updates within a minute or two.
