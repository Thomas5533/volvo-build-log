# Volvo Project build log

Build log for a 1989 Volvo 240 DL: installed parts, races, maintenance, future mods, photos and contributors.

**Live site:** https://thomas5533.github.io/volvo-build-log/

## Editing the site

1. Open the live site and click **Owner sign-in** at the very bottom of the page.
2. Paste your GitHub access key (a fine-grained token for this repository with **Contents: Read and write**). It stays in that browser only.
3. Edit anything on the page. Each change is saved straight to this repository, and visitors see it within a few minutes.

Visitors without a key see a read-only page. Photos you add on the site are stored in the `photos` folder.
